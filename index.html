Features

Everything an access review needs, nothing it doesn't

Built for security leads, product owners and engineers who need a clear answer to "who can do what, and why".

Roles with hierarchy

Model humans, service accounts and AI agents. Inherit permissions from a parent role instead of repeating them.

Screens and features

Register what needs protecting, grouped by module, with a risk level so reviews start with the sensitive parts.

Permissions matrix

Click View, Create, Edit, Delete, Approve and Export per role and resource. Inherited access shows up on its own.

Separation of duties

Declare pairs of roles that must never be combined, and get a warning when inheritance would break the rule.

Diagram

See roles, inheritance and permissions as a diagram, with high-risk resources outlined.

Private by design

No account, no server, no tracking. Your model lives in this browser, and a JSON backup is one click away.

How it works

From a blank page to an access model in four steps

Start from the built-in example or clear it and begin with your own roles.

Roles

Define roles by business function, not by menus, and let them inherit.

Resources

Register screens and features, group them by module and set the risk.

Matrix

Click the letters to grant permissions to each role.

Review and export

Filter the effective permissions, see the diagram, then export the documentation.

Export

Documentation you can hand over

The PDF report holds the roles, the permissions matrix with inherited access, and the separation-of-duties constraints. Copy the rest straight into Notion, Confluence, Excel or mermaid.live.

FAQ

Questions

Where is my data stored?

Only in your browser (local storage). There is no account and no server. Use Export → JSON to keep a backup or move to another device.

Does it cost anything?

No. It is free and open source under the MIT license.

Do I need an internet connection?

The app itself runs offline once loaded. The PDF export loads the jsPDF library from a CDN the first time.

Is this an access-control system?

No. It is a design and documentation tool: it records the model you intend to implement, so you can review it before you build it.
